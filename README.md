# Сметко — smetko.com

Математика като игра за 1.–4. клас. Чист HTML, CSS и JavaScript, без CMS. Работи като PWA, включително офлайн.

- Сайтът е в папка `public_html/`.
- При всяка промяна в клон `main` GitHub Actions го качва автоматично в SuperHosting (`.github/workflows/deploy.yml`).
- Локален преглед: отворете `public_html/index.html` в браузъра.

Подробности: `ПРОЧЕТИ-МЕ.md`.
