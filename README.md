# Сметко — smetko.com

Математика като игра за 1.–4. клас. Чист HTML, CSS и JavaScript, без CMS. Работи като PWA, включително офлайн.

- Сайтът е в папка `public_html/`.
- При всяка промяна в клон `main` GitHub Actions го качва автоматично в SuperHosting (`.github/workflows/deploy.yml`).
- Локален преглед: отворете `public_html/index.html` в браузъра.

Подробности: `ПРОЧЕТИ-МЕ.md`.

## Проверки

```
sh tests/run.sh
```

Вдига местен сървър на 127.0.0.1:8093 (`tests/serve.sh`, с `tests/router.php` вместо
.htaccess), нулира базата (`tests/setup.py`) и пуска двата пакета:

* `tests/smoke.py` – всяка страница от картата на сайта се отваря и е цяла, нищо не
  излиза встрани на 320–1440 px, шапката се побира, връзките водят донякъде,
  иконите ги има и сайтът е безплатен.
* `tests/content.py` – моделът на НВО (16/4/5, 25 задачи, 100 точки, 60 минути),
  сборникът, блогът и съдържанието му, работните листове в трите вида, пробните
  тестове и една задача от играта.

Преди качване: `python3 tools/build.py && python3 tools/seo.py && sh tests/run.sh`.
