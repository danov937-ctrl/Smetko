# Сметко (smetko.com): версия 1

## Как да го видите веднага
Разархивирайте и отворете `public_html/index.html` в браузъра (двоен клик). Всичко работи и локално.

## Качване в SuperHosting
1. Влезте в cPanel → **File Manager** → папка `public_html`.
2. Качете **съдържанието** на папката `public_html` от архива (не самата папка).
3. Файлът `.htaccess` е скрит. В File Manager включете Settings → „Show Hidden Files“, за да проверите, че е качен.
4. Отворете https://smetko.com, всичко трябва да работи.

## Какво има
| Файл | Какво е |
|---|---|
| `index.html` | Начална страница (по вашия прототип) |
| `game.html` | Играта: избор → карта на мисиите → игра → резултат |
| `class-1..4.html` | SEO страници за всеки клас с теми |
| `pricing.html` | Цени и абонаменти |
| `about.html` | За Сметко, за родители (#roditeli), за учители (#uchiteli) |
| `achievements.html` | Точки, нива, значки, рекорди |
| `privacy-policy.html`, `terms.html` | Шаблони: **попълнете жълтите полета [ПОПЪЛНЕТЕ]** |
| `js/math-engine.js` | Генератор на задачи: 28 теми × 3 нива |
| `js/gamification.js` | Точки, 10 нива, 14 значки, серии от дни |
| `js/owl.js` | Сметко като SVG в 6 пози |
| `js/app.js` | Общи настройки (`Smetko.config`) |
| `sw.js`, `manifest.json` | PWA: инсталиране на телефона и игра без интернет |

## Важни настройки (`js/app.js` → `Smetko.config`)
- `paywall: false`: всичко е отключено. Сменете на `true`, когато пуснете абонаментите. Тогава безплатно остават „Бързо сметни“, първите 3 мисии за клас и 20 задачи на ден в Тренировка.
- `contactEmail: 'info@smetko.com'`: създайте тази пощенска кутия в cPanel или сменете адреса (той е и в HTML файловете).

## При промяна на CSS/JS
Сменете `?v=1` на `?v=2` в HTML файловете и `VERSION` в `sw.js`. Така браузърите ще изтеглят новите файлове.
